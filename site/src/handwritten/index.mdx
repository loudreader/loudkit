<section id="where-it-runs">

<div class="lk-section-head">
  <p class="lk-eyebrow">Where it runs</p>
  <h2>Laptops, GPUs and edge devices.</h2>
  <p>Faster than real time on datacentre GPUs, on desktop GPUs, on Apple Silicon and on an embedded board. Every figure is one <code>loudkit bench</code> run on the named machine. <a href="/loudkit/benchmarks/">The hardware, the method and the commands</a>.</p>
</div>

<div class="lk-grid">

  <CudaCard />

  <div class="lk-card">
    <p class="lk-req">requires Apple Silicon</p>
    <h3>Apple GPU</h3>
    <div class="lk-metric">3.43&times;<span>real time, M-series laptop, <code>{'--device mps'}</code></span></div>
    <p>The generator runs on the CPU and the renderer on the GPU. A CoreML renderer ships for Swift.</p>
  </div>

  <div class="lk-card">
    <p class="lk-req">requires no PyTorch</p>
    <h3>ONNX Runtime</h3>
    <div class="lk-metric">1.21&times;<span>real time, same laptop, fp32 graphs</span></div>
    <p>Runs without PyTorch, on ONNX Runtime.</p>
  </div>

  <div class="lk-card">
    <p class="lk-req">an embedded NVIDIA GPU</p>
    <h3>Jetson Orin Nano</h3>
    <div class="lk-metric">1.83&times;<span>real time, <code>{'--device cuda --cuda-graphs'}</code>, measured on the board</span></div>
    <p>The same engine, the same conformance fixture, on a board with no discrete GPU.</p>
  </div>

</div>

<p class="lk-section-foot">Every figure is a multiple of real time. 3&times; real time means one minute of audio in twenty seconds. Under 1&times; is slower than real time.</p>

</section>

<section id="sdks">

<div class="lk-section-head">
  <p class="lk-eyebrow">Five languages, one engine</p>
  <h2>Ports, not wrappers.</h2>
  <p>Python is the reference implementation. Swift, Go, Rust and TypeScript are full ports of it, and all five are held to the same conformance fixture, so the same text and the same voice give the same speech tokens in every one.</p>
</div>

<div class="lk-sdks">
  <div class="lk-sdk"><strong>Python</strong><span>PyTorch, ONNX Runtime or CoreML backend</span><em>reference</em></div>
  <div class="lk-sdk"><strong>Swift</strong><span>CoreML backend</span><em>Swift Package Manager</em></div>
  <div class="lk-sdk"><strong>Go</strong><span>ONNX Runtime backend</span><em>go get</em></div>
  <div class="lk-sdk"><strong>Rust</strong><span>ONNX Runtime backend</span><em>cargo</em></div>
  <div class="lk-sdk"><strong>TypeScript</strong><span>ONNX Runtime backend</span><em>npm i</em></div>
</div>

<section id="install">

<div class="lk-section-head">
  <p class="lk-eyebrow">Install</p>
  <h2>Install, then speak.</h2>
  <p>Add the package, load a checkpoint, pick a voice, get a waveform. Python fetches what it needs on the first call. The ONNX ports read files from disk, so they fetch first into <code>loudr-1/</code>, which is what the paths below are relative to.</p>
</div>

<Tabs syncKey="language">
  <TabItem label="Python">
    ```bash
    pip install "loudkit[torch,audio,hub]"
    ```

    ```python
    import loudkit as lk

    engine = lk.load("loudreader/loudr-1")
    voice = lk.voice("kathleen", repo="loudreader/loudr-1")
    engine.synthesize("Hello from loudkit.", voice, seed=7).save("hello.wav")
    ```
  </TabItem>
  <TabItem label="TypeScript">
    ```bash
    npm i loudkit
    ```

    ```bash
    pip install "loudkit[hub]"
    loudkit download loudreader/loudr-1 --for onnx --local-dir loudr-1
    ```

    ```typescript
    import { Engine, loadVoice } from "loudkit";

    const engine = await Engine.load(
      "loudr-1/loudr-1.safetensors", "loudr-1/onnx", "loudr-1/tokenizer.json");
    const voice = loadVoice("loudr-1/voices/kathleen.safetensors");

    const result = await engine.synthesize("Hello from loudkit.", voice, 7);
    // result.audio is a Float32Array at result.sampleRate.
    ```
  </TabItem>
  <TabItem label="Go">
    ```bash
    go get github.com/loudreader/loudkit/go
    ```

    ```bash
    pip install "loudkit[hub]"
    loudkit download loudreader/loudr-1 --for onnx --local-dir loudr-1
    ```

    ```go
    // Point onnxruntime_go at libonnxruntime first. See the Go guide.
    eng, _ := engine.Load(
        "loudr-1/loudr-1.safetensors", "loudr-1/onnx", "loudr-1/tokenizer.json")
    defer eng.Close()
    v, _ := voice.Load("loudr-1/voices/kathleen.safetensors")

    // After the seed: language, speed, previousTokens, shouldCancel.
    audio, _, _, _, sr, _, _ := eng.SynthesizeLong(
        "Hello from loudkit.", v, 7, "", 1.0, nil, nil)
    ```
  </TabItem>
  <TabItem label="Rust">
    ```toml
    loudkit = "0.1"
    ```

    ```bash
    pip install "loudkit[hub]"
    loudkit download loudreader/loudr-1 --for onnx --local-dir loudr-1
    ```

    ```rust
    let mut eng = Engine::load(
        "loudr-1/loudr-1.safetensors", "loudr-1/onnx", "loudr-1/tokenizer.json")?;
    let v = voice::load("loudr-1/voices/kathleen.safetensors")?;

    // After the seed: language, speed, previous_tokens, should_cancel.
    let (audio, tokens, _, sr, _, _) =
        eng.synthesize_long("Hello from loudkit.", &v, 7, None, 1.0, None, None)?;
    ```
  </TabItem>
  <TabItem label="Swift">
    ```swift
    // Swift Package Manager
    .package(url: "https://github.com/loudreader/loudkit", from: "0.1.0")
    ```

    ```bash
    pip install "loudkit[hub]"
    loudkit download loudreader/loudr-1 --for coreml --local-dir loudr-1
    ```

    ```swift
    import Foundation
    import LoudKit

    let engine = try Engine.load(
        checkpoint: URL(fileURLWithPath: "loudr-1/loudr-1.safetensors"))
    let voice = try VoiceProfile.load(
        url: URL(fileURLWithPath: "loudr-1/voices/kathleen.safetensors"))

    let result = try engine.synthesize("Hello from loudkit.", voice: voice, seed: 7)
    try result.save(to: URL(fileURLWithPath: "hello.wav"))
    ```
  </TabItem>
</Tabs>

<p class="lk-section-foot">The same seed and voice give the same speech tokens in all five. The four ports load graphs exported once from a Python checkout: ONNX for TypeScript, Go and Rust, CoreML for Swift. Each guide has that step.</p>
