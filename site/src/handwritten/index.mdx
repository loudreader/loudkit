<section id="where-it-runs">

<div class="lk-section-head">
  <p class="lk-eyebrow">Where it runs</p>
  <h2>Laptops, GPUs and edge devices.</h2>
  <p>Faster than real time on datacentre GPUs, desktop GPUs, Apple Silicon and an embedded board. The Python figures come from <code>tools/bench.py</code>. The Swift figures are medians of three warm streams from <code>tools/bench_ports</code>. The batch figures come from <code>research/bench_batch.py</code>. <a href="/loudkit/benchmarks/">The hardware, the method and the commands</a>.</p>
</div>

<div class="lk-grid">

  <CudaCard />

  <div class="lk-card">
    <p class="lk-req">requires Apple Silicon</p>
    <h3>Apple GPU</h3>
    <div class="lk-metric">5.77&times;<span>real time with loudr-1-turbo, M3 Pro laptop, <code>{'--device mps'}</code>; loudr-1 runs 3.29&times;</span></div>
    <p>The token generator runs on the CPU and the renderer on the GPU. The Swift port, with its CoreML renderer, runs 3.44&times; with turbo and 2.49&times; with loudr-1 on the same laptop.</p>
  </div>

  <div class="lk-card">
    <p class="lk-req">no PyTorch needed</p>
    <h3>ONNX Runtime</h3>
    <div class="lk-metric">1.59&times;<span>real time with loudr-1-turbo, same laptop, CPU provider, fp32 graphs; loudr-1 runs 1.14&times;</span></div>
    <p>Runs without PyTorch, on ONNX Runtime, in Python, Go, Rust and TypeScript.</p>
  </div>

  <div class="lk-card">
    <p class="lk-req">an embedded NVIDIA GPU</p>
    <h3>Jetson Orin Nano Super</h3>
    <div class="lk-metric">2.50&times;<span>real time with loudr-1-turbo at 25&nbsp;W, <code>{'--device cuda --cuda-graphs'}</code>; loudr-1 runs 1.85&times;</span></div>
    <p>On the board, the same engine reproduces the reference tokens of the conformance fixture cases.</p>
  </div>

</div>

<p class="lk-section-foot">Figures are multiples of real time: 3&times; means one minute of audio in twenty seconds, and under 1&times; is slower than real time. The batch figures count the audio-equivalent output of the token generator only. All figures were measured on 0.1.1 with both models and are quoted from <a href="/loudkit/benchmarks/">the benchmark page</a>, which records the machines, the versions and the commands.</p>

  <h2>Five native implementations.</h2>
  <p>Python is the reference implementation. Swift, Go, Rust and TypeScript are ports of it. All five pass the same conformance fixture, and the <a href="/loudkit/reference/identity-contract/">identity contract</a> states where their speech tokens match.</p>

<section id="install">

<div class="lk-section-head">
  <p class="lk-eyebrow">Install</p>
  <h2>Install and synthesize.</h2>
  <p>Install the package, load a model by name, choose a voice and synthesize. The first load downloads and verifies the release. Later loads run offline.</p>
</div>

<Tabs syncKey="language">
  <TabItem label="Python">
    ```bash
    pip install "loudkit[torch,audio,hub]"
    ```

    ```python
    import loudkit as lk

    engine = lk.load("loudreader/loudr-1")
    voice = engine.voice("joe")
    engine.synthesize("Hello from loudkit.", voice, seed=7).save("hello.wav")
    ```
  </TabItem>
  <TabItem label="TypeScript">
    ```bash
    npm i loudkit@0.1.1
    ```

    ```typescript
    import { Engine } from "loudkit";

    const engine = await Engine.load("loudreader/loudr-1");
    const voice = engine.voice("joe");
    (await engine.synthesize("Hello from loudkit.", voice, { seed: 7 })).saveWav("hello.wav");
    await engine.close();
    ```
  </TabItem>
  <TabItem label="Go">
    ```bash
    go get github.com/loudreader/loudkit/go@v0.1.1
    ```

    ```go
    eng, err := loudkit.Load("loudreader/loudr-1")
    if err != nil { log.Fatal(err) }
    defer eng.Close()
    v, err := eng.Voice("joe")
    if err != nil { log.Fatal(err) }
    res, err := eng.Synthesize("Hello from loudkit.", v, loudkit.Options{Seed: 7})
    if err != nil { log.Fatal(err) }
    if err := res.SaveWav("hello.wav"); err != nil { log.Fatal(err) }
    ```
  </TabItem>
  <TabItem label="Rust">
    ```toml
    loudkit = "0.1.1"
    ```

    ```rust
    use loudkit::{Engine, Options};

    let mut engine = Engine::load("loudreader/loudr-1")?;
    let voice = engine.voice("joe")?;
    let options = Options { seed: 7, ..Default::default() };
    engine.synthesize("Hello from loudkit.", &voice, &options)?.save_wav("hello.wav")?;
    ```
  </TabItem>
  <TabItem label="Swift">
    ```swift
    // Package.swift
    .package(url: "https://github.com/loudreader/loudkit", from: "0.1.1")
    ```

    ```swift
    import LoudKit

    let engine = try await Engine.load("loudreader/loudr-1")
    let voice = try engine.voice(named: "joe")
    try engine.synthesize("Hello from loudkit.", voice: voice, seed: 7).saveWav("hello.wav")
    ```
  </TabItem>
</Tabs>

<p class="lk-section-foot">Go and Rust need <code>libonnxruntime</code> on the machine; each guide says where its port looks for it. <code>loudreader/loudr-1</code> and <code>loudreader/loudr-1-turbo</code> both run in all five implementations. All 28 voices are included in both model downloads and load by name.</p>

<section id="responsible-use">

<div class="lk-section-head">
  <h2>Responsible use.</h2>
  <p>loudkit clones a voice from about ten seconds of audio. Get the speaker's consent before you clone a voice. By default, WAVs saved from Python and the server carry a machine-readable note on how the audio was made. <a href="/loudkit/responsible-use/">Read the responsible-use guide</a>.</p>
</div>
