<section id="where-it-runs">

<div class="lk-section-head">
  <p class="lk-eyebrow">Where it runs</p>
  <h2>Laptops, GPUs and edge devices.</h2>
  <p>Faster than real time on datacentre GPUs, on desktop GPUs, on Apple Silicon and on an embedded board. Every figure is one run of <code>tools/bench.py</code> or a port runner on the named machine. <a href="/loudkit/benchmarks/">The hardware, the method and the commands</a>.</p>
</div>

<div class="lk-grid">

  <CudaCard />

  <div class="lk-card">
    <p class="lk-req">requires Apple Silicon</p>
    <h3>Apple GPU</h3>
    <div class="lk-metric">5.77&times;<span>real time with loudr-1-turbo, M3 Pro laptop, <code>{'--device mps'}</code>; loudr-1 runs 3.29&times;</span></div>
    <p>The generator runs on the CPU and the renderer on the GPU. Swift's CoreML renderer runs 3.44&times; with turbo and 2.49&times; with loudr-1 on the same laptop.</p>
  </div>

  <div class="lk-card">
    <p class="lk-req">requires no PyTorch</p>
    <h3>ONNX Runtime</h3>
    <div class="lk-metric">1.59&times;<span>real time with loudr-1-turbo, same laptop, CPU provider, fp32 graphs; loudr-1 runs 1.14&times;</span></div>
    <p>Runs without PyTorch, on ONNX Runtime, in Python, Go, Rust and TypeScript.</p>
  </div>

  <div class="lk-card">
    <p class="lk-req">an embedded NVIDIA GPU</p>
    <h3>Jetson Orin Nano</h3>
    <div class="lk-metric">2.50&times;<span>real time with loudr-1-turbo, <code>{'--device cuda --cuda-graphs'}</code>, measured on the board; loudr-1 runs 1.85&times;</span></div>
    <p>The same engine, the same conformance fixture, on a board with no discrete GPU.</p>
  </div>

</div>

<p class="lk-section-foot">Every figure is a multiple of real time. 3&times; real time means one minute of audio in twenty seconds. Under 1&times; is slower than real time. Every figure was measured on 0.1.1 with both models and is quoted from <a href="/loudkit/benchmarks/">the benchmark page</a>, which records the machines, the versions and the commands.</p>

<section id="sdks">

<div class="lk-section-head">
  <p class="lk-eyebrow">Five languages, one engine</p>
  <h2>Ports, not wrappers.</h2>
  <p>Python is the reference implementation. Swift, Go, Rust and TypeScript are full ports of it, and all five are held to the same conformance fixture, so the same text and the same voice give the same speech tokens in every one.</p>
</div>

<section id="install">

<div class="lk-section-head">
  <p class="lk-eyebrow">Install</p>
  <h2>Install, then speak.</h2>
  <p>Add the package, load the model by name, pick a voice, get a waveform. Every language fetches the release on the first load, verifies it, and runs offline after that.</p>
</div>

<Tabs syncKey="language">
  <TabItem label="Python">
    ```bash
    pip install "loudkit[torch,audio,hub]"
    ```

    ```python
    import loudkit as lk

    engine = lk.load("loudreader/loudr-1")
    voice = engine.voice("joe")
    engine.synthesize("Hello from loudkit.", voice, seed=7).save("hello.wav")
    ```
  </TabItem>
  <TabItem label="TypeScript">
    ```bash
    npm i loudkit@0.1.1
    ```

    ```typescript
    import { Engine } from "loudkit";

    const engine = await Engine.load("loudreader/loudr-1");
    const voice = engine.voice("joe");
    (await engine.synthesize("Hello from loudkit.", voice, { seed: 7 })).saveWav("hello.wav");
    await engine.close();
    ```
  </TabItem>
  <TabItem label="Go">
    ```bash
    go get github.com/loudreader/loudkit/go@v0.1.1
    ```

    ```go
    eng, err := loudkit.Load("loudreader/loudr-1")
    if err != nil { log.Fatal(err) }
    defer eng.Close()
    v, err := eng.Voice("joe")
    if err != nil { log.Fatal(err) }
    res, err := eng.Synthesize("Hello from loudkit.", v, loudkit.Options{Seed: 7})
    if err != nil { log.Fatal(err) }
    if err := res.SaveWav("hello.wav"); err != nil { log.Fatal(err) }
    ```
  </TabItem>
  <TabItem label="Rust">
    ```toml
    loudkit = "0.1.1"
    ```

    ```rust
    use loudkit::{Engine, Options};

    let mut engine = Engine::load("loudreader/loudr-1")?;
    let voice = engine.voice("joe")?;
    let options = Options { seed: 7, ..Default::default() };
    engine.synthesize("Hello from loudkit.", &voice, &options)?.save_wav("hello.wav")?;
    ```
  </TabItem>
  <TabItem label="Swift">
    ```swift
    // Package.swift
    .package(url: "https://github.com/loudreader/loudkit", from: "0.1.1")
    ```

    ```swift
    import LoudKit

    let engine = try await Engine.load("loudreader/loudr-1")
    let voice = try engine.voice(named: "joe")
    try engine.synthesize("Hello from loudkit.", voice: voice, seed: 7).saveWav("hello.wav")
    ```
  </TabItem>
</Tabs>

<p class="lk-section-foot">The same seed and voice give the same speech tokens in all five. Go and Rust need <code>libonnxruntime</code> on the machine; each guide says where its port looks for it. <code>loudreader/loudr-1</code> runs everywhere; <code>loudreader/loudr-1-turbo</code> is supported by all five ports in 0.1.1. All 28 voices are included in both model downloads and load by name.</p>
